# Med-Self-Preference LaTeX manuscript

`main.tex` is a self-contained, upload-ready LaTeX manuscript. It uses only
standard TeX packages and contains the references directly, so no `.bib` file
or local data files are required.

Compile locally with:

```bash
tectonic main.tex
```

Before submission, replace the placeholder author names and email address in
the title block. The identity-revealed experiment is explicitly labeled as an
in-progress snapshot and should be updated when that run completes.
